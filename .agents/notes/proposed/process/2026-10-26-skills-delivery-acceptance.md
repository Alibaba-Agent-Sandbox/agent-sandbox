# Decision: Verify Skill delivery with observed workflows and bounded claims

Status: proposed

## Problem
The17 requested workflow requirements cannot be established by counting tools or installing instruction files. A previous credential blocker was incorrect: the authorized workspace environment contains usable cloud and GitHub credentials.

## Decision
Run three collaborating implementation/test streams plus independent adversarial reviews against a selected real Express environment. Maintain a requirement-level matrix with evidence, initial failures, fixes, cleanup and unverified prerequisites. Exercise an installed Qwen Code Skill through actual MCP tools. Keep account billing data in a private user artifact and publish only sanitized coverage receipts.

## API Design
N/A — this record describes acceptance. Separate feature records own resource verification, native Template Cache operations and atomic session shutdown.

## Alternatives considered
A tool/schema-only coverage number cannot establish persistence, process recovery, billing attribution, GUI takeover or managed hosting. Unbounded account cleanup and creating an unrelated cluster are outside this acceptance.

## Dependencies
Authorized credentials, one selected existing Team/region, source CLI/SDK candidates and official platform APIs. Native WarmPool, workload/cost attribution and permanent managed MCP service inputs remain incomplete.

## Test Strategy
Independent observable effects, before/after regression tests and cloud readback. Preserve all initial failures separately. Run owner full gates and report environmental network-audit failures rather than changing product behavior to suppress them. Verify PR CI and the deployed bilingual website.

## Acceptance criteria
- Every one of17 items has a stated real scenario, result and boundary.
- New runtime defects have deterministic regression, independent review and real-cloud verification.
- Only owned resources are cleaned; independent absence is recorded.
- Tracking Issue46 stays open while any requested acceptance remains incomplete.
