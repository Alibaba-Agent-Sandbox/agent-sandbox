# Decision: Publish the next minimal CLI patch with current runtime inputs

Status: proposed

## Problem

Fresh-install developer reruns found standalone launch, generated preparation and duplicated startup issues. Current template tooling also mixed old project source pins with public Python releases, and the automatic wheel downloader incorrectly used the independent CLI version as its Python runtime version.

## Decision

Publish CLI 0.5.2 after the scoped fixes, required checks and actual generated artifacts pass. All project-owned Python installation recipes use public client/server 0.4.0a2. Remove the obsolete archive constants and matching branches instead of retaining compatibility aliases. Keep explicit local development source/version overrides. Update the optional Undici 8 dependency to patched 8.12.2 without changing standard CLI/protocol source versions.

## API Design

No new CLI option, schema version, workflow mode or migration layer. MCP generated configuration uses the current ABX domain variable. A patch version is sufficient for these corrections.

## Alternatives considered

- Keep separate old scaffold/MCP source pins: rejected because users and tooling should use the same current release.
- Infer Python versions from the CLI version: rejected because the packages are independently versioned.
- Broad dependency upgrades: rejected; update only the affected optional HTTP dependency patch.

## Dependencies

Merged launch and JSON fixes, public paired Python 0.4.0a2, locked standard source replay, five-platform release artifacts, npm publication and website mirror.

## Test Strategy

Run owner checks, real Docker wheel/runtime tests, actual generated MCP ASGI initialization/auth/catalog, actual model-to-cloud generation and exact cleanup. Publish only after latest-head CI and independent review. Then install from official public npm/binary/PyPI endpoints and repeat the five developer journeys. Preserve candidate, failed and released-package results separately.

## Acceptance criteria

- Latest-head required CI and artifact checks pass.
- Generated templates, scaffolds and MCP artifacts use the same public runtime requirement.
- CLI and Python runtime version defaults remain independent.
- CLI 0.5.2 npm and five binaries are publicly installable and checksummed.
- Fresh public-install reruns and exact owned cleanup are recorded.
