# 模板项目中的原生表达式

模板 v1 使用一个资源文件。Serving 配置沿用 Devs 原生项目结构，保留所选组件的
props。Sandbox 和应用配置通过同一项目上下文解析引用，不另建一套模板表达式语言。

例如，原生 `${env('MODEL_API_KEY')}` 读取指定环境变量，`${vars.model}` 读取项目变量。
原生 `file` 返回文本，读取 JSON 属性使用 `${json(file('./values.json')).model}`。
相对文件以资源文件所在项目目录为基准。

缺少必需引用时，预览或执行必须停止，并给出可定位的字段路径。私有值不应进入公开
资源文件明文、普通输出、持久化计划或镜像构建上下文。静态模板发现不应要求解析
凭据或本地文件。

声明原生 action 与执行 action 是不同操作。计划必须显示所声明的 action，只有真实
承接其生命周期的执行路径才可以运行。原生组件语法本身不代表通用 Serving 部署、
资源归属或安全删除已经实现。托管 Agents 继续保留明确的候选验证、旧 Session 路由
和 drain 行为。
