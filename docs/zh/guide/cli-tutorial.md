# CLI 使用路径

先完成[入门](getting-started.md)的配置、部署、调用和清理。随后按任务继续：

- [操作速查](operations.md)：具名部署、Sandbox 进程与文件工具。
- [使用模板](using-templates.md)：目录发现、固定 Git 源码和直接部署。
- [编写模板](authoring-templates.md)：内置初始化、模型生成、适配代码、可复用构建和源码发布。
- [配置与认证](guided-configuration.md)：凭据用途、本机保存、自动化覆盖。
- [托管应用](managed-applications.md)：独立业务端点和生命周期。

命令行选项以 [CLI 参考](../reference/cli-commands.md)和当前安装版 `--help` 为准。源码生成不自动创建云资源，部署会使用所选 Provider 创建运行实例。
