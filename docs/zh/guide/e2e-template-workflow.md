# 模板完整使用路径

按[模板编写](authoring-templates.md)获取或生成可编辑源码，再按[部署与构建](deploy-and-build.md)部署。用[模板部署与清理](template-launch.md)核对启动、认证、失败恢复和资源归属。

实际验证应调用模板的业务 API、检查结果与生成文件，并删除本轮拥有的资源。版本查询、健康检查或构建成功不能替代业务验证。模型任务还需要该模型端点支持模板实际使用的工具回合。

已有固定版本的验收记录保留在所属仓库工程证据中；它们不能替代当前模板、Provider、账号和区域的验证。贡献者的测试层级见[端到端测试](testing-e2e.md)。
