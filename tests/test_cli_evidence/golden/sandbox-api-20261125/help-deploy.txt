Usage: abx deploy [options] [SOURCE]

Deploy a catalog template or local project. --name identifies this deployment.
Resource specVersion: 1 prepares templates and Serving; use create --template
for an instance. Source spec_version: 5 also starts its declared instance.
--plan previews without building or deploying.

Options:
  --name <NAME>
  --plan
  --bindings <BINDINGS>            Private application binding references JSON
                                   file.
  --build-profile <BUILD_PROFILE>
  --build-timeout <FLOAT>
  --sandbox-timeout <INTEGER>      Source spec_version: 5 instance lifetime in
                                   seconds (default: 300).
  --request-timeout <FLOAT>
  --upload <UPLOAD>
  --on-timeout <ON_TIMEOUT>        (choices: "pause", "kill")
  --auto-resume
  -e, --env <ENV>
  -m, --metadata <METADATA>
  --volume-mount <VOLUME_MOUNT>
  -y, --yes
  -h, --help                       Show this message and exit.
[exit_code:0]
