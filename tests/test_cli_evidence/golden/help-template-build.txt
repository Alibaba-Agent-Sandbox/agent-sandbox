Usage: abx template build [options] [TEMPLATE_DIR]

Build Docker image locally, push to ACR, and create a sandbox template.

Full pipeline with cloud side effects: the local docker build is
local-only, but the ACR push and the remote template registration
can incur Alibaba Cloud costs (ACR storage/traffic, template
resources).

Supports two modes:

--official-api (default):
  local docker build → ACR push → official CreateTemplate API (envdInject).
  Requires AK/SK credentials (set with 'abx config init --build').

--legacy-api:
  local docker build → ACR push → legacy v3/v2 platform API.
  Use --legacy-api to keep the old behaviour.

Requires Docker daemon running and ACR credentials. In automation/CI,
pass --acr-namespace and TEMPLATE_DIR explicitly instead of relying
on ACR_NAMESPACE / ABX_TEMPLATE_DIR environment variables or .env
files, so the build cannot drift with the surrounding environment.

Examples:
  abx template build ./examples/templates/python-hello \
    --acr-namespace my-ns --acr-repo python-hello
  abx template build ./my-template \
    --acr-namespace prod --acree-instance-id cri-xxx
  abx template build ./my-template \
    --acr-namespace prod --disk-size 10240 --internet-access
  abx template build ./my-template \
    --acr-namespace prod --legacy-api
  abx template build ./my-template --acr-namespace prod --region cn-shanghai

Related commands:
  abx template init DIRECTORY    Scaffold template source files
  abx template push IMAGE        Push an existing local image only
  abx create --template ID       Launch the completed template

Options:
  --acr-registry <ACR_REGISTRY>            ACR registry host
  --acr-namespace <ACR_NAMESPACE>          ACR namespace (env: ACR_NAMESPACE, or set in .env file)
  --acr-repo <ACR_REPO>                    ACR repository name (defaults to template.yaml name or dir name)
  --acr-username <ACR_USERNAME>            ACR login username (defaults to AccessKey from .env)
  --acr-password <ACR_PASSWORD>            ACR login password (defaults to AccessSecret from .env)
  --acree-instance-id <ACREE_INSTANCE_ID>  ACR EE instance ID (cri-...)
  --vpc-id <VPC_ID>                        VPC ID for ACR EE
  --vswitch-ids <VSWITCH_IDS>              Comma-separated VSwitch IDs
  --security-group-id <SECURITY_GROUP_ID>  Security group ID
  -a, --alias <ALIAS>                      Template alias
  -t, --tag <TAG>                          Docker image tag
  --platform <PLATFORM>                    Target platform
  --cpu <INTEGER>                          CPU cores (default: from template.yaml resources.cpu, fallback 2)
  --memory <INTEGER>                       Memory in MB (default: from template.yaml resources.memory, fallback 2048)
  --start-cmd <START_CMD>                  Container start command
  --ready-cmd <READY_CMD>                  Container readiness check command
  --timeout <INTEGER>                      Build timeout in seconds
  -f, --dockerfile <PATH>                  Custom Dockerfile path
  --disk-size <INTEGER>                    Disk size in MB (official API only)
  --internet-access                        Internet access (default: platform decides; official API only)
  --no-internet-access                     Opposite of --internet-access.
  --official-api                           Use official CreateTemplate API (default) or legacy v3/v2
  --legacy-api                             Opposite of --official-api.
  --team-id <TEAM_ID>                      Team ID for official API (or env TEAM_ID / E2B_TEAM_ID)
  --envd-inject                            Enable envd injection (default False)
  --no-envd-inject                         Opposite of --envd-inject.
  --generation <INTEGER>                   Sandbox generation (default: template.yaml 'generation', otherwise 1). 1=first-gen (rund), 2=second-gen MicroVM.
  --target-image <TARGET_IMAGE>            Destination image ref for envd copy (auto-derived with random suffix if omitted)
  -y, --yes                                Skip confirmation prompt
  -v, --verbose                            Verbose output (DEBUG level)
  -r, --region <TEXT>                      Region override for this command (default: 'abx config set region' value, else cn-hangzhou)
  -h, --help                               Show this message and exit.
