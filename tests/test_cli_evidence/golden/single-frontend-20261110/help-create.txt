Usage: abx create [options]

Create a Sandbox from a ready template build or a Provider-native template ID.

Options:
  --name <NAME>
  --template-id <TEMPLATE_ID>
  --build <BUILD>                Ready Sandbox artifact from abx template build.
  --sandbox-timeout <INTEGER>
  --request-timeout <FLOAT>
  --upload <UPLOAD>
  --on-timeout <ON_TIMEOUT>      (choices: "pause", "kill")
  --auto-resume
  -e, --env <ENV>
  -m, --metadata <METADATA>
  --volume-mount <VOLUME_MOUNT>
  -y, --yes
  -h, --help                     Show this message and exit.
[exit_code:0]
