Usage: abx logs [options] <TARGET>

Read deployment logs. Sandbox service logs use the template startup log;
--source platform selects native sandbox logs.

Options:
  --source <SOURCE>  (choices: "service", "platform")
  --role <ROLE>      (choices: "gateway", "worker", "dispatcher")
  -f, --follow
  --lines <INTEGER>
  -h, --help         Show this message and exit.
