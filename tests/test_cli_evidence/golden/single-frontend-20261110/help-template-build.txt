Usage: abx template build [options] [SOURCE]

Prepare a reusable template from a Registry reference or local source without
creating an instance. Use --out to save the artifact for abx create or abx
deploy.

Options:
  --out <OUT>
  --clean <CLEAN>                  Clean owned resources from an unused build
                                   artifact; retain its journal.
  --build-profile <BUILD_PROFILE>
  -a, --alias <ALIAS>
  --timeout <FLOAT>                Sandbox template preparation timeout in
                                   seconds (default 600).
  -y, --yes
  -h, --help                       Show this message and exit.
[exit_code:0]
