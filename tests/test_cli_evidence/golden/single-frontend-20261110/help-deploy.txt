Usage: abx deploy [options] [SOURCE]

Prepare named Sandbox templates and volumes, and deploy Serving. --name
identifies the application. --plan previews resources without building or
deploying.

Options:
  --name <NAME>
  --build <BUILD>          Reuse a ready resource build artifact.
  --plan
  --build-timeout <FLOAT>
  -y, --yes
  -h, --help               Show this message and exit.
[exit_code:0]
