Usage: abx deploy [options] [SOURCE]

Deploy a managed application from a catalog template, local project or build.
Use --plan to preview its resources.

Options:
  --name <NAME>
  --build <BUILD>        Reuse a managed application build artifact.
  --plan
  --bindings <BINDINGS>  Private application binding references JSON file.
  -y, --yes
  -h, --help             Show this message and exit.
[exit_code:0]
