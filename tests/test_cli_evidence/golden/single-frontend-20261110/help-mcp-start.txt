Usage: abx mcp start [options]

Start the MCP server and print its configuration to stderr.

The default transport is STDIO: an IDE writes JSON-RPC to stdin and reads
responses from stdout. Run it in a terminal to see the configuration and
stop it with Ctrl-C or 'abx mcp stop'.

--http listens for Streamable HTTP. --background detaches that HTTP
server; STDIO cannot keep a client attached after detach, so --background
starts HTTP.

Examples:
  abx mcp start
  abx mcp start --template python-hello
  abx mcp start --http --port 9000
  abx mcp start --http --background
  abx mcp stop

Related commands:
  abx mcp install --target cursor  Register the STDIO command in an IDE
  abx mcp stop                     Stop the local MCP server
  abx mcp status                   Check authentication and IDE setup

Options:
  --template <TEMPLATE>      Default sandbox template ID or alias (default:
                             code-interpreter-v1).
  --api-key <API_KEY>        API key override.
  --api-url <API_URL>        API URL override.
  --domain <DOMAIN>          Domain override.
  --http                     Serve Streamable HTTP instead of STDIO.
  --host <HOST>              HTTP bind address. [default: 127.0.0.1]
  --port <INTEGER>           HTTP bind port. [default: 9000]
  --auth-token <AUTH_TOKEN>  Bearer token for the HTTP server. Required when
                             --host is not loopback.
  --background               Detach an HTTP server. Stop it later with 'abx mcp
                             stop'.
  -h, --help                 Show this message and exit.
[exit_code:0]
